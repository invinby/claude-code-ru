# Claude Code RU

Русские описания команд `/`, настройки и доступные элементы интерфейса Claude Code.
Перевод работает локально: статический словарь, без сетевых запросов и без расхода
токенов при использовании. Подходит и для Claude Code с API Kimi: провайдер и
выбранная модель не меняются.

**Это не полный перевод клиента.** Поддерживается то, что движок предоставляет
модам. Окна разрешений, стартовый экран, некоторые вложенные меню, системные ошибки
и `claude --help` могут оставаться английскими. Количество записей в словаре не
означает процент перевода интерфейса. Незнакомые строки показываются оригинальными.

## Установка

Нужен Claude Code с поддержкой модов (2.1.287+). Проверки проекта выполняются на
Windows с Claude Code 2.1.310; остальные версии требуют отдельной проверки.

Внутри Claude Code:

```text
/plugin marketplace add invinby/claude-code-ru
/plugin install cc-ru@claude-code-ru
```

Откройте новую сессию `claude`. Для проверки разовой локальной копии:

```powershell
claude --plugin-dir ./mods/cc-ru
```

При клонированном репозитории на Windows можно запустить
`./scripts/Install.ps1`. Скрипт использует штатные команды установки плагинов.

## Что переводится

- Описания команд и подсказки аргументов в меню `/`.
- Названия и пояснения настроек, предоставленные `config.describe`.
- Доступные статусы работы, подсказки, уведомления и метки режимов.
- Сводки известных групп инструментов и длительность хода.

Рабочие имена команд (`/model`, `/config`), сочетания клавиш, идентификаторы
моделей и значения настроек сохраняются. Пользовательские ответы, исходный код,
вывод терминальных программ, разрешения и запросы к модели не переписываются.

`/ru-status` показывает число словарных записей и счётчики увиденных
непереведённых описаний. Он не отправляет данные в сеть и не сохраняет разговоры.
Для русских ответов самой модели отдельно установите `"language": "russian"`
в пользовательском `~/.claude/settings.json`. Плагин не изменяет этот файл вручную.

## Отключение и удаление

```text
/plugin disable cc-ru@claude-code-ru
/plugin uninstall cc-ru@claude-code-ru
```

Также доступен `./scripts/Uninstall.ps1`. Другие плагины, ключи и история
разговоров не удаляются. После изменения откройте новую сессию.

## Проверки

```powershell
claude plugin validate ./mods/cc-ru --strict
claude plugin test ./mods/cc-ru
python ./scripts/check_dictionary.py
```

Тесты проверяют настоящий механизм описаний команд и настроек, сохранение
служебных полей, неизвестных строк, динамических значений и обработку повреждённого
словаря. Для меню требуется и ручная проверка реального терминала.

## Дополнение словаря

`mods/cc-ru/dict.json` содержит точные пары `exact`: исходная строка → перевод.
Не используйте догадки или обрезанный текст с экрана в качестве ключа. Добавляйте
точные исходные строки из текущей версии, сохраняйте placeholders, backticks,
ключи конфигурации, команды и смысл отрицаний. После обновления запускайте тесты.
Вручную проверяйте формулировки, связанные с разрешениями и областью действия.
