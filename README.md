## Установка

Введите две команды **внутри Claude Code**:

```text
/plugin marketplace add invinby/claude-code-ru
/plugin install cc-ru@claude-code-ru
```

Затем откройте новую сессию `claude`. Нужна версия с поддержкой модов — **2.1.287 или новее**.

## Что станет понятнее

- **Меню `/`** — русские описания команд и подсказки аргументов.
- **Настройки** — доступные названия и пояснения строк `/config`.
- **Ход работы** — доступные статусы, подсказки, уведомления и сводки инструментов.

> **Перевод частичный.** Некоторые заголовки, окна разрешений, вложенные меню и `--help`
> остаются английскими. [Проверенное покрытие и ограничения →](docs/verification.md)

Имена команд, клавиши, код и значения настроек сохраняются. Плагин работает со
статическим словарём: сам не вызывает модель и не меняет выбранного API-провайдера.
Подходит и для Claude Code с Kimi.

## Совместимость

| Система | Статус |
| :--- | :--- |
| **Windows** | Проверено на Claude Code **2.1.310** |
| **macOS** | Предусмотрена общая установка; пока не протестировано |
| **Linux** | Предусмотрена общая установка; пока не протестировано |

Команды установки одинаковы для всех трёх систем. Проверка Windows не гарантирует
совместимость с каждой последующей версией Claude Code.

## Управление

| Действие | Команда внутри Claude Code |
| :--- | :--- |
| Проверить состояние перевода | `/ru-status` |
| Временно отключить | `/plugin disable cc-ru@claude-code-ru` |
| Удалить | `/plugin uninstall cc-ru@claude-code-ru` |

Для русских **ответов модели** отдельно задайте `"language": "russian"`
в `~/.claude/settings.json`. Это другая настройка; мод её не меняет.

<details>
<summary><strong>Разработка, проверка и дополнение словаря</strong></summary>

Для разового запуска из клонированного репозитория:

```sh
claude --plugin-dir ./mods/cc-ru
```

Проверки:

```sh
claude plugin validate ./mods/cc-ru --strict
claude plugin test ./mods/cc-ru
python ./scripts/check_dictionary.py
```

В [словаре](mods/cc-ru/dict.json) раздел `exact` содержит пары «исходная строка → перевод».
Сохраняйте placeholders, имена команд, ключи настроек и смысл отрицаний.
Неизвестные строки остаются исходными. После изменения словаря откройте новую
сессию или выполните `/reload-plugins`.

На Windows также доступны [установщик](scripts/Install.ps1) и
[скрипт удаления](scripts/Uninstall.ps1). Тесты и проверка установки описаны
в [протоколе](docs/verification.md).

</details>
