# cc-ru

Русский интерфейс доступных поверхностей Claude Code через штатные моды.
Плагин переводит описания команд, названия настроек, некоторые подсказки,
уведомления, статусы и сводки. Использует только локальный словарь: не вызывает
модель, не меняет провайдера, API-ключи или решения о разрешениях. Незнакомые
строки сохраняет. Это частичная локализация: встроенные окна, не предоставленные
API модов, остаются на исходном языке. Подробности установки, проверки и удаления
находятся в корневом README репозитория. Состояние перевода доступно через /ru-status.

Установка: `/plugin install cc-ru --marketplace invinby/claude-code-ru`.
