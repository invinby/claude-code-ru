## Ограничения

Всю закрытую часть интерфейса мод не переводит. Системные окна разрешений, стартовый экран, некоторые встроенные ошибки, заголовки/вложенные пункты меню, `--help`, неизвестные статусы и новые описания после обновлений могут остаться английскими.

Основной словарь содержит машинный перевод с ручными исправлениями ключевых строк. Все переводы не проходили независимую лингвистическую проверку. В спорных случаях сверяйтесь с исходной строкой в словаре.

Словарь читается один раз при загрузке: после его изменения нужна новая сессия или `/reload-plugins`. Во время разработки разово использовался API для чернового перевода строк; установленный плагин не вызывает модель и не делает сетевых запросов.
