# Claude Code RU — проект русификации

Цель: русские описания встроенных команд /, настройки и доступные через API модов элементы терминального интерфейса Claude Code 2.1.310. Не менять запросы к модели, инструменты, API-ключи и правила разрешений.

## Подход
Отдельный плагин cc-ru на официальном механизме модов: локальный словарь английский → русский, обработчики command.describe, config.describe и разрешённых точек ui.render. Словарь переводится заранее, без запросов к модели при работе. Незнакомая строка остаётся оригинальной. Не переводить исходный код, пути, вывод пользовательских программ или аргументы команд. Команды /model и другие сохраняют рабочие идентификаторы; переводятся их описания.

Альтернативы: патч нативного бинарника хрупок и не поддерживается выбранным проектом; внешняя оболочка не переводит настоящий интерфейс и не соответствует запросу.

## Ограничение полного покрытия
Изученный действующий китайский мод указывает, что окна подтверждения разрешений, стартовый экран, часть вложенных меню /config и /model, CLI --help и некоторые встроенные сообщения не доступны его обработчикам. Это должно проверяться на текущем CLI; покрытие этих поверхностей заранее не обещается. Если полная русификация всех поверхностей обязательна, этот подход не удовлетворяет требованию: понадобится расширение API upstream или другой клиент.

## Состав репозитория
Плагин, отдельный русский словарь, лицензия на собственный код и необходимые уведомления об использованных исходниках, русская документация, установка/удаление, тесты сохранения значений и совместимости. В репозитории нет настроек пользователя, ключей, журналов разговоров и бинарника Anthropic.

## Проверка
Валидатор плагинов текущей версии; тесты известных и неизвестных строк, неизменности идентификаторов/путей, отсутствия сетевых вызовов и изменений разрешений; проверка меню / в реальном терминале; список непереведённых поверхностей. Только после этих проверок — установка и публикация. Полным переводом называть результат лишь при подтверждённом полном покрытии.
